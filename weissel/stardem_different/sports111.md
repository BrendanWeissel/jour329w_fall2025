### How to Read the Table
* **Ch** = State Champion (the school won the state title).  
* **Fn** = State Finalist / Runner‑up (the school lost in the final).  
* **Sf** = State Semifinalist (lost in the semifinal).  
* **QF** = State Quarterfinalist (lost in the quarterfinal).  
* **RS** = Regional Semifinalist, **RR** = Regional Runner‑up, **RR2** = Regional 2nd‑Round, **RR1** = Regional 1st‑Round.  
* When multiple years are listed, each year is a separate appearance in that category.
