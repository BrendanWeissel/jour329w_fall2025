My original plan was to try and make a website using CoPilot. I tried to do that and the output was ugly (looked like it was from 2010) and I could not get the LLM to produce enough info for it to be useful for a website. The idea of a dropdown is very cool but I don't actually think it would be that helful for a reporter. 

I decided it would be more useful to create something that the reporter can use in addition to a beat book that could be updated each year and provide context to the sports in the Bayside confrence. 

I took the fall record book from the MPSSAA which tracks all the championchips in Maryland sports history. I decided to look just at the fall season but this would be repeatable for all seasons. 

Using ChatGpt I created a prompt that only looks at Bayside athletic confrence teams and tracks all of their Md state titles and notable performances. 

This is a good tool to have to compare how teams are doing historicaly and compare them that season. It can quickly give context to the schools past success and help with writing articles like "how does this team compare to the 2018 golf team when Easton won it all."

I am persoanlly very interested in historicall championships so this is a tool I would use. 

It could be expanded for confrence titles and all 3 seasons of sports. This could be another tool to create a beatbook based on schools sports history instead of using articles.
